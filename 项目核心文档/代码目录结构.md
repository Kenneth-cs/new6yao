## 二、主代码目录 `liuyao/`

### 📱 App 入口
| 文件 | 说明 |
|------|------|
| `liuyaoApp.swift` | App 入口，配置 CoreData、环境注入 |
| `ContentView.swift` | 根视图，决定展示 MainTabView 还是引导页 |
| `MainTabView.swift` | **底部 Tab 导航**（5个核心Tab） |

---

### 🗂 底部 Tab 视图（5个核心功能）

| Tab | 文件 | 功能说明 |
|-----|------|---------|
| 1 - 学习 | `LearningCenterView.swift` | 学习中心入口页 |
| 2 - 思考 | `ThinkingToolsView.swift` | 思维工具箱（SWOT、决策矩阵等） |
| 3 - 摇卦 | `DecisionAnalysisView.swift` | 六爻AI分析入口（摇卦功能） |
| 4 - 决策 | `MatrixPlaceholderView.swift` | **五行决策矩阵（开发中占位）** |
| 5 - 我的 | `ProfileCenterView.swift` → `ProfilePageView.swift` | 个人中心 |

---

### 🔮 核心功能页（摇卦 / 六爻分析）

### 🧠 思维工具

### 🎯 五行决策矩阵（开发中）

| 文件 | 功能说明 |
|------|---------|
| `MatrixPlaceholderView.swift` | Tab 占位页，显示"功能开发中" |
| `BaziEngine.swift` | **[核心]** 本地八字排盘引擎（计算五行分值、喜忌神） |
| `ScoreCalculator.swift` | **[核心]** 本地评分算法（加权计算、熔断风控） |
| `MatrixDecisionService.swift` | 协调 AI 接口与本地算法的中间层 |
| `EnergyPortraitView.swift` | 首页：动态流体圆环与 AI 文案展示 |
| `ScenarioSelectionView.swift` | 场景选择页 |
| `ParticleCollisionView.swift` | 过程页：粒子碰撞动画 |
| `MatrixResultView.swift` | 结果页：决策报告与对比矩阵 |
| `MatrixResultPreviewView.swift` | UI 原型页，展示五步决策报告的 Mock 效果 |
