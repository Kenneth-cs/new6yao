## 三、数据流设计

### 3.1 canonical_interpretation_summary 组装策略

不需要 AI 再次生成摘要，从已有 `aiInterpretation` 中提取：

```swift
// 在 DeductionPrepView 或 AIService.performDeduction 中：
let parsed = MasterReportParser.parse(aiInterpretation)
let coreConclusion = parsed.sections["核心结论"] ?? ""
let coreVerdict    = parsed.sections["核心断语"] ?? ""

var summary = ""
if !coreConclusion.isEmpty { summary += "核心结论：\(coreConclusion)" }
if !coreVerdict.isEmpty    { summary += "\n\n核心断语：\(coreVerdict)" }
// 合计约 100-200字，约 150-300 tokens
```

**选择这两个章节的原因**：
- **核心结论**（Section ①）：50-80字大白话，告诉推演 AI "用户当前局势+该怎么做"
- **核心断语**（Section ④）：50-120字专业摘要，告诉推演 AI "本卦的核心卦理是什么"
- 不选「时间提示」：与三路推演相关度低，推演不涉及时间节点
- 不选「这卦最需要警惕什么」：推演 AI 依据卦理自行判断边界，不受原解读的边界框限

## 四、新增 Swift 数据模型

### 4.1 DeductionReport（推演响应主模型）

```swift
struct DeductionReport: Codable {
    let reportVersion: String
    let question: String
    let backgroundUsed: String
    let globalJudgment: GlobalJudgment
    let recommendation: Recommendation
    let paths: [DeductionPathResult]
    let reportFooter: String

    struct GlobalJudgment: Codable {
        let title: String
        let summary: String
        let divinationBasisSummary: String
        let informationGaps: [String]
    }

    struct Recommendation: Codable {
        let status: String                    // "clear" | "conditional" | "insufficient"
        let recommendedPathId: String?        // "advance" | "hold" | "withdraw" | null
        let headline: String
        let reason: String
        let applicableConditions: [String]
        let reconsiderWhen: [String]
    }

    struct DeductionPathResult: Codable, Identifiable {
        let id: String                        // "advance" | "hold" | "withdraw"
        let fixedName: String
        let rank: Int
        let isRecommended: Bool
        let pathAssumption: TextBlock
        let pathVerdict: TextBlock
        let developmentTrend: DevelopmentTrend
        let pathDivinationReasoning: DivinationReasoning
        let verificationSignals: VerificationSignals
    }

    struct TextBlock: Codable {
        let title: String
        let content: String
    }

    struct DevelopmentTrend: Codable {
        let title: String
        let opening: String
        let development: String
        let turningPoint: String
        let possibleOutcome: String

        var cardContent: String {
            [opening, development].filter { !$0.isEmpty }.joined(separator: "\n\n")
        }
    }

    struct DivinationReasoning: Codable {
        let title: String
        let originalHexagram: String
        let movingLines: String
        let changedHexagram: String
        let relationAndUseGod: String
        let pathSymbolism: String
    }

    struct VerificationSignals: Codable {
        let title: String
        let signals: [String]

        var cautionText: String {
            signals.prefix(3).joined(separator: "；")
        }
    }
}
```

CodingKeys 对应 JSON 的 snake_case / 中文 key，需补充完整的 `CodingKeys` enum。
