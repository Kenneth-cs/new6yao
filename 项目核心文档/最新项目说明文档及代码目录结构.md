## 二、产品定位

一款融合古代智慧与现代科技的个人成长助手应用。通过 AI 驱动的智慧启发系统，为用户提供个性化的人生指导、决策支持和成长陪伴。

核心理念：**启发而非预测，成长而非依赖，实用而非玄学，陪伴而非说教。**

## 三、底部 Tab 结构（5 Tab）

| Tab | 名称 | 对应 View | 说明 |
|-----|------|-----------|------|
| 0 | 学习 | `LearningCenterView` | 文章知识库，支持分类筛选与搜索 |
| 1 | 思考 | `ThinkingToolsView` | 思维工具箱入口，含 SWOT、决策矩阵等 |
| 2 | 摇卦 | `DecisionAnalysisView` | 六爻摇卦，输入问题 → 抛铜币 → AI 解卦 |
| 3 | 决策 | `EnergyPortraitView` | 五行能量画像 + 五行决策矩阵，核心功能 |

默认选中 **Tab 2（摇卦）**。

## 四、已有功能清单

### 4.1 摇卦（六爻预测）

**流程**：输入问题 → 6 次抛铜币 → 生成卦象 → AI 深度解卦

| 文件 | 职责 |
|------|------|
| `DecisionAnalysisView.swift` | 摇卦首页，显示时间、定位、入口按钮与快捷场景 |
| `DivinationPageView.swift` | 问题输入页，支持 500 字限制，检查免费额度 |
| `CoinTossPageView.swift` | 铜币抛掷页，6 次摇动/点击触发动画，生成卦象 |
| `DivinationResultPageView.swift` | 结果页，展示卦象 + AI 四段式解读（卦象分析/问题解读/综合指导/行动建议） |
| `ScenarioSelectionView.swift` | 快捷场景选择（事业/投资/情感/置业/出行） |
| `MethodologyView.swift` | 方法论说明弹窗 |

- AI 模型：DeepSeek V3
- 支持前后台切换继续请求
- 结果保存到 Core Data 历史记录

### 4.2 五行决策矩阵

**流程**：输入生辰 → 计算命局 → 选择场景 → 输入选项 → 粒子碰撞动画 → AI 五行决策报告

| 文件 | 职责 |
|------|------|
| `EnergyPortraitView.swift` | 决策 Tab 首页，五行能量画像，生辰输入与命局展示 |
| `ScenarioSelectionView.swift` | 五行场景选择（事业/投资/情感/置业/出行） |
| `ParticleCollisionView.swift` | 五行粒子碰撞沉浸式动画页 |
| `MatrixResultViewB.swift` | 最终决策报告页（STEP 结构 + 矩阵表格 + 落地手册） |
| `BaziEngine.swift` | 八字排盘引擎，计算天干地支、五行强弱 |
| `MatrixModels.swift` | 五行数据模型（FiveElement、EnergyPortraitResult 等） |
| `MatrixResultV2Models.swift` | V2 决策结果模型 |
| `MatrixHistoryStore.swift` | 五行决策历史本地存储 |
| `MatrixAlgorithmDemo.swift` | 矩阵算法演示/调试 |
| `MatrixPlaceholderView.swift` | 占位视图 |
| `MatrixResultPreviewView.swift` | 结果预览视图 |

- 免费用户每月 10 次，订阅用户无限
- 五行：木/火/土/金/水
- 支持 2-N 个选项对比决策

### 4.3 SWOT 分析

| 文件 | 职责 |
|------|------|
| `SWOTAnalysisView.swift` | SWOT 四象限输入 + AI 深度分析 |

- 输入：问题标题 + 优势/劣势/机会/威胁
- AI 一键深度分析，支持前后台切换
- 免费用户每月 10 次

### 4.4 决策矩阵工具

| 文件 | 职责 |
|------|------|
| `DecisionMatrixView.swift` | 多方案加权评分矩阵，2+ 选项对比评估 |

- 输入：问题标题 + 多个选项 + 权重评分
- AI 辅助分析

## 五、技术架构

### 5.1 App 入口

| 文件 | 职责 |
|------|------|
| `liuyaoApp.swift` | `@main` App 入口，初始化 Core Data、通知、埋点 |
| `MainTabView.swift` | 5-Tab 主视图，管理 Tab 切换与导航 |
| `ContentView.swift` | 内容视图（早期入口，现由 MainTabView 替代） |
| `SharedComponents.swift` | 全局共享 UI 组件 |

### 5.2 AI 服务层

| 文件 | 职责 |
|------|------|
| `AIService.swift` | AI 解卦服务，构建 prompt、调用 API、解析结果 |
| `NetworkService.swift` | 网络请求层，对接火山方舟 DeepSeek V3 API，支持重试、超时、后台任务 |
| `AIModels.swift` | AI 请求/响应数据模型 |
| `AIRequestStateStore.swift` | AI 请求状态管理（支持前后台切换恢复） |

- **AI 模型**：`deepseek-v3-250324`
- **API Endpoint**：`https://ark.cn-beijing.volces.com/api/v3/chat/completions`
- 连接超时 15s，读取超时 180s，最多重试 2 次

### 5.3 数据埋点

**后端地址**：`https://www.superindividual.youqukeji.cn`
