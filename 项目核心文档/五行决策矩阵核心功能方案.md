# 五行决策矩阵：通用产品方案文档

## 文档说明
本文档旨在“人生教练”App中定义“五行决策矩阵”核心功能的算法逻辑、数据结构及用户流程。该功能将玄学命理（八字五行、易经）转化为可量化、可视化的决策辅助工具，帮助用户在职业、置业、人际、投资等场景下做出符合自身命局优势的选择。

---

## 一、 核心研发策略：混合架构 (Hybrid Architecture)

为确保**运算准确性**与**交互灵活性**，本功能采用 **“本地算法 (Hard Logic) + AI 大模型 (Soft Logic)”** 的混合模式。

### 1. 架构分工
| 环节 | 负责方 | 技术实现 | 核心价值 |
| :--- | :--- | :--- | :--- |
| **1. 八字排盘** | **本地 Swift** | `BaziEngine` (基于天文历法) | **严谨性**：确保天干地支、节气、藏干计算零误差，避免AI数学幻觉。 |
| **2. 能量画像** | **AI 接口** | 字节豆包 API (Prompt: 角色扮演) | **温度感**：将冷冰冰的“土旺水弱”翻译为“你是燥土，急需雨露滋润”。 |
| **3. 选项打标** | **AI 接口** | 字节豆包 API (Prompt: 知识库) | **广度**：利用世界知识库，识别“腾讯(火)”、“产品经理(水/木)”等任意输入。 |
| **4. 核心打分** | **本地 Swift** | `ScoreCalculator` (加减权/熔断) | **控制权**：掌握评分生杀大权，确保“一票否决”等风控逻辑严格执行。 |
| **5. 最终建议** | **AI 接口** | 字节豆包 API (Prompt: 咨询师) | **高情商**：基于得分生成落地建议和调候物推荐。 |

### 2. 核心底层逻辑：药病原理与平衡

系统不仅仅是寻找“五行相生”的选项，而是基于**“中和为贵”**的原则，识别命局的“病”与“药”。

*   **病（Imbalance）**：用户命局中过旺、导致失衡的五行（忌神）。
*   **药（Remedy）**：能制衡“病”、补足弱项的五行（喜用神）。
*   **决策本质**：寻找含“药”量最高的选项，同时规避含“病”的选项。

### 3. 决策评分公式 (本地执行)


设选项总分 $S$，利于命局的五行为 $W_b$（补益/喜用），不利的为 $W_h$（损耗/忌神）。

$$ S = \sum (W_b \times \text{权重}) - \sum (W_h \times \text{权重}) + M_t $$

*   **$W_b$ (Benefit)**：选项中包含的喜用神属性分值。
*   **$W_h$ (Harm)**：选项中包含的忌神属性分值。
*   **$M_t$ (Momentum)**：时空动量修正值（见下文“易经动量”）。
*   **权重设定**：
    *   核心属性（行业/本质）：1.5
    *   辅助属性（方位/数字/颜色）：1.0
    *   冲克关系（刑冲克害）：2.0

#### ⚠️ 风险控制：一票否决机制
若选项中存在**极度忌神**或**严重刑冲**（如：大运流年与选项发生天克地冲，或选项五行触犯命局最忌讳的“死穴”），无论总分多高，系统必须触发**熔断**。
*   **表现**：直接判定为“高风险/淘汰”，并弹出红色警告（如：“此选项金气过旺，触犯命局官杀，恐惹官非口舌”）。

## 三、 进阶逻辑：易经动量分析 (V2规划)

除了静态的五行匹配，引入“时间”和“变数”维度：

1.  **时位关系（Seasonality）**：
    *   评估决策当下的**月令（季节）**。
    *   *逻辑*：如果用户喜木，且当前是寅卯月（春季），则所有属木的选项得分上浮 10%-15%（得天时）。
2.  **变爻预警（Volatility）**：
    *   对于“高风险/投资”类决策，后台可引入简单的**梅花易数**逻辑（利用时间起卦）。
    *   若得出的卦象为“六冲”或“游魂”，提示该选项存在隐性变数，建议“缓行”或“再议”。

## 四、 用户使用流程 (User Flow)

### 1. 能量画像构建 (Onboarding)
*   **输入**：出生年、月、日、时、出生地。
*   **处理**：
    *   后台排盘，计算八字旺衰。
    *   确定喜用神（药）与忌神（病）。
*   **输出**：
    *   **“五行能量雷达图”**：可视化展示命局缺什么、什么过多。
    *   **文案**：“你的命局核心是【弱木】，你的能量补给站是【水】和【木】（药），你的能量黑洞是【土】和【金】（病）。”

### 2. 场景选择 (Templates)
用户点击“发起决策”，选择场景以激活对应的标签模板：
*   🏛️ **职场/学业**（预设：行业属性、公司方位、老板生肖）
*   💰 **投资/理财**（预设：赛道五行、风险属性、入场时机）
*   🏠 **置业/生活**（预设：楼层、朝向、区域、装修色调）
*   🤝 **人际/情感**（预设：对方生肖、性格特征、初见月份）

### 3. 选项录入 (Input & Tagging)
采用**向导式问答**与**自动标签化**结合：
*   **用户操作**：输入选项名称（如“腾讯总部”）。
*   **系统处理**：
    *   **自动抓取**：关键词匹配“互联网” -> 自动打标【火】。
    *   **手动补充**：用户补选“位于南方” -> 自动打标【火】。

### 4. 矩阵模拟与计算 (The Matrix)
*   **展示形式**：屏幕模拟五行流转动画。
*   **过程**：
    *   将选项的五行标签投入用户的“命局池”。
    *   相生（如水生木）产生绿色光效（加分）。
    *   相克（如金克木）产生红色震动（减分）。
    *   **触发一票否决**：若触碰红线，立即停止动画并报警。

### 5. 决策报告与调候建议 (Output)
*   **最终结论**：
    *   🏆 **优选**（大吉）：药力充足，生生不息。
    *   ✅ **可行**（小吉）：利大于弊，可控。
    *   ⚠️ **慎重**（平/凶）：消耗过大，需补救。
    *   🚫 **淘汰**（大凶）：触犯红线，建议放弃。
*   **长期收益预测**：基于五行平衡度，预测未来3-5年的运势走向。
*   **调候方案（商业化连接点）**：
    *   若用户必须选择“慎重”项（如：工作必须去西方，但忌金），系统给出**“通关”**方案。
    *   *建议示例*：“建议办公桌摆放黑曜石摆件（属水），通关金木之战。” -> **链接至商城/法器推荐**。

## 五、 UI/UX 与商业化建议 (详细方案见《五行决策矩阵UI_UX落地方案.md》)

### 1. 视觉交互设计 (Visual Design)
本功能采用 **“新中式赛博 (Neo-Chinese Cyber)”** 风格，将传统命理与现代数据可视化深度融合。

*   **首页：五行能量画像 (Energy Portrait)**
    *   **核心视觉**：摒弃雷达图，采用**动态流体圆环**。五色光影代表能量强弱（过旺则扩散光晕，缺失则为虚线）。
    *   **文案降维**：将“财多身弱”等术语翻译为“你是燥土，急需雨露滋润”等说明书式文案。
    *   **入口**：底部紫色渐变按钮“开始决策 ->”。

*   **场景选择页 (Scenario Selection)**
    *   **风格**：水墨晕染背景 + 轻量化悬浮卡片。
    *   **交互**：支持搜索与自定义场景，预设“事业(木)、投资(水)、情感(火)、置业(土)”等分类。

*   **过程页：能量粒子碰撞 (Particle Collision)**
    *   **沉浸式体验**：深色宇宙背景，模拟粒子（选项五行）飞入命局池（黑洞）的动态过程。
    *   **熔断反馈**：若触发“一票否决”（如强力忌神），屏幕剧烈震动并闪烁**红色呼吸警示光**，弹出“高风险”阻断弹窗。

*   **结果页：决策报告 & 对比矩阵 (Result & Matrix)**
    *   **头部定论**：青蓝色渐变Banner，直观展示“优选：选项A”及“85分-大吉”。
    *   **得分拆解**：进度条对比“药力（补益）”与“病灶（损耗）”。
    *   **对比矩阵**：纵向排列决策维度（如楼层、方位）。
        *   **补益**：绿色背景 + 向上箭头 ⬆️ + [水/木]标签。
        *   **消耗**：黄色背景 + 向下箭头 ⬇️ + [火]标签。
        *   **忌神**：红色边框 + 警示图标 ⚠️ + [金-忌神]标签。

### 2. 商业化切入点
*   **Level 1（免费）**：基础五行分析、简单的二选一决策。
*   **Level 2（订阅/付费）**：
    *   解锁“粒子碰撞”深度分析动画。
    *   生成详细的PDF决策报告（包含未来3-5年运势预测）。
    *   解锁多维度（3个以上）选项对比。
*   **Level 3（电商转化 - 闭环）**：
    *   **调候物推荐**：在结果页直接嵌入商品卡片。
    *   *场景*：若决策结果显示“缺水”，下方推荐“黑曜石手链”并附带购买链接。
