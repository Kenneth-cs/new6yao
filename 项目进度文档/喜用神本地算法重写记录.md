# 喜用神本地算法重写记录

> 版本：五行完整版 2.1（commit `21eec42`）
> 日期：2026年03月03日

---

## 一、背景与问题

在五行能量画像页面中，"急需补充的能量"和"喜用神"原先完全由 AI（deepseek-v3）在线判断。用户多次反馈：

- 同一人多次进入，结论不一致（AI 温度波动导致）
- 大多数人都得到"缺金，喜水木"，结论单一不准
- 出现"庚金日主忌金"、"丙火的喜用神是水"等明显错误
- AI 受本地占比数据"诱导"，逻辑自相矛盾（急需补充的能量与忌神重叠）

**核心结论**：喜用神由规则决定，不应依赖 AI 概率性输出。

---

## 二、算法设计

### 2.1 有效强度公式

```
eff = 日主% - 官杀%×0.5 - 财星%×0.3 - 食伤%×0.2 + 印星%×0.3
```

考虑了四种力量对日主实际强度的影响权重。

### 2.2 官克等身修正

当 `官杀% ≥ 日主% × 0.9` 时，无论 eff 数值如何，都视为身弱。
处理"木40% vs 金41%"这类竞争激烈格局（表面旺实质受克）。

### 2.3 判断分支（6种情况）

| 情况 | 触发条件 | 喜用神 | 代表案例 |
|------|----------|--------|----------|
| 旺 + 印过旺 | eff≥0.25 且 印星>35% | 财克印 + 官制身 | 丁火春卯：木41%旺生火 → 喜金水 |
| 旺普通 | eff≥0.25 | 官/食/财中最低2个（官优先） | 丁火夏午 → 喜金水 |
| 弱 + 水多木漂 | 印=水, 日主=木, 水>40% | 食伤（火）+ 财克印（土） | 乙木冬亥：水54% → 喜火土 |
| 弱 + 金多水浑 | 印=金, 日主=水, 金>40% | 食伤（木）+ 财克印（火） | 壬水秋申：金52% → 喜木火 |
| 弱 + 食伤过旺 + 冬月 | 食伤>40% 且月支亥/子/丑 | 印制食 + 火调候 | 辛金冬亥：水65% → 喜土火 |
| 弱普通 | 其余 | 印星 + 比劫（同元素） | 甲木秋酉：金克木 → 喜水木 |

### 2.4 weakElement 定义

```
weakElement = 喜用神中占比最低的元素
```
即"有益但最匮乏"的能量，绝不会出现在忌神中（自洽保证）。

## 三、代码变更

### `liuyao/BaziEngine.swift`

新增内容：

1. **`calculateFavorableElements(date:hour:)`** — 对外接口，输入出生信息，返回 `(favorable:[String], unfavorable:[String], weakElement:String)`

2. **`static favorableRule(dayMaster:scores:isColdMonth:)`** — 核心规则引擎（静态方法，便于单元测试直接调用）

3. **`extension FiveElement`** — 新增五行生克关系计算属性：
   - `generates`（我生 = 食伤）
   - `generatedBy`（生我 = 印星）
   - `controls`（我克 = 财星）
   - `controlledBy`（克我 = 官杀）

### `liuyao/AIService.swift`

`analyzeEnergyPortrait()` 函数重构：

**改动前**：AI 负责判断 `favorableElements`、`unfavorableElements`、`weakElement`，每次可能不同。

**改动后**：
- `favorableElements`、`unfavorableElements`、`weakElement` 全部由 `BaziEngine.calculateFavorableElements()` 本地计算（确定性，永远一致）
- AI 只负责生成 `diagnosis`（60~90字命局描述）和 `remedy`（35~55字补充建议文字）
- Prompt 中明确告知 AI "这些字段已由本地精确计算，必须原样输出"

### `liuyaoTests/BaziEngineTests.swift`

新增两个测试函数：

1. **`testFavorableElementsAccuracy()`** — 断言10个标准案例的喜用神计算结果与公认答案一致
2. **`testWeakElementNotInUnfavorable()`** — 断言 weakElement 始终属于喜用神、不属于忌神（自洽性验证）

## 五、修复的典型问题

| 问题 | 改动前（AI）| 改动后（本地）|
|------|------------|--------------|
| 庚金日主 | 有时判断"忌金" | 正确：身弱喜土金 |
| 丙/丁火日主 | 有时判断"喜用神是水" | 正确：身弱时喜木火；身旺时才喜水 |
| 壬水申月 | 多次判断"缺金喜水木" | 正确：金多水浑，喜木火泄金 |
| 乙木亥月 | 有时输出"喜水木" | 正确：水多木漂，改喜火土 |
| 结论一致性 | 同人多次不同结论 | 永远相同（确定性本地计算）|
