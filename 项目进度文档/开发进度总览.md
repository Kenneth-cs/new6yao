## 二、进行中功能

### 🚧 五行决策矩阵（完整版）

**背景**：将玄学命理（八字五行）转化为可量化的决策辅助工具。

**当前进度**：
- [x] 产品方案文档完成（见 `项目核心文档/五行决策矩阵核心功能方案.md`）
- [x] AI Prompt 设计完成（见 `项目核心文档/AI_Prompt_Design.md`）
- [x] 算法 Demo 原型完成（`MatrixAlgorithmDemo.swift`）
- [x] UI 原型完成（`MatrixResultPreviewView.swift`，使用 Mock 数据）
- [x] 底部 Tab 占位（`MatrixPlaceholderView.swift`，显示"功能开发中"）
- [ ] 用户八字/喜忌神录入页面
- [ ] 决策问题 + 选项录入页（向导式）
- [ ] 对接 AI API，替换 Mock 数据
- [ ] 五步法结果页正式上线
- [ ] 与订阅系统打通（高级功能付费）

**技术方案**：
- 存储：Core Data（本地）
- 计算：Swift 本地算法引擎
- AI：调用字节豆包 API，通过 Prompt 控制输出 JSON 格式
